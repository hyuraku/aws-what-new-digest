# 2026年02月23日

## [S3] Amazon S3 Tables are now available in AWS GovCloud (US) Regions

- **公開日**: 2026-02-23 (JST)
- **カテゴリ**: S3
- **リンク**: https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-s3-tables-aws-govcloud-us/

### 概要

Amazon S3 Tables（Apache Iceberg対応のテーブル型ストレージ）が AWS GovCloud (US-East) と AWS GovCloud (US-West) で利用可能になりました。ガバメント向けリージョンでIceberg互換の大規模タブularデータ管理とコスト最適化機能が利用できます。

### 変更内容・新機能の詳細

S3 Tables はオブジェクトストレージ上でネイティブにApache Iceberg標準をサポートするテーブル型ストレージを提供します。主な特徴は次の通りです：
- Apache Iceberg互換性：スナップショット、タイムトラベル、スキーマ進化などIcebergの機能が利用でき、Iceberg対応のクエリエンジン（例：Amazon Athena、Apache Spark、Trinoなど）から直接クエリ可能です。
- 継続的なテーブルメンテナンス：自動コンパクションやファイルサイズ最適化、メタデータ（マニフェスト・スナップショット）管理により、クエリ効率やストレージコストを時間経過で最適化します。
- ストレージクラス連携：Intelligent-Tiering と連携し、アクセスパターンに応じた自動階層化でコスト削減を図りつつ、パフォーマンスや運用負荷に影響を与えません。
- ガバメントリージョン適用：これまでは商用リージョンで提供されていた機能がGovCloud(US-East/US-West)でも利用可能になり、政府向けや規制対象データのワークロードでもS3 Tablesを使えます。
- 相互運用性：Iceberg標準に準拠しているため、サードパーティのIceberg対応ツールや既存のIcebergテーブルとの互換性が期待できます。
リージョン対応状況はS3 Tablesのリージョンとエンドポイント一覧で確認してください。

### 影響範囲・利用シーン

- **対象ユーザー**: 政府機関・規制対象のデータを扱う組織、クラウド上で大規模データレイクを運用するデータエンジニア/分析チーム
- **利用シーン**: GovCloud内でのデータレイク構築、Iceberg互換の解析基盤（Athena/Spark/Trinoなど）による分析、タイムトラベルやスキーマ進化を伴うETL/データカタログ運用
- **運用効果**: 自動コンパクションとIntelligent-Tieringによりクエリ性能維持とストレージコスト最適化を同時に実現し、手動のメンテナンス負荷を低減できます

### 技術的な注意点

- **IAM権限**: S3 Tables の作成・管理には既存のS3権限に加え、テーブル管理用の追加権限（テーブル作成/メタデータ操作等）が必要になる場合があります。事前にポリシーを確認してください。
- **リージョン制限**: 現時点でのGovCloud対応は AWS GovCloud (US-East) および AWS GovCloud (US-West) のみ。その他リージョンでの利用可否は公式リージョン一覧を確認してください。
- **コスト**: S3 Tables自体の利用はストレージ・リクエスト・データ転送などの通常のS3課金対象になります。継続的なメンテナンス（自動コンパクション等）による追加リクエストやデータ書き込みが発生し、コストに影響する可能性があります。
- **互換性**: クエリエンジン側でサポートしているIcebergのバージョンや設定（メタデータの配置、カタログ設定等）を確認する必要があります。既存のIcebergテーブルを移行する場合はメタデータ互換性とアクセス設定を検証してください。
- **データ居住性／コンプライアンス**: GovCloudアカウント要件やデータ居住性・規制要件を満たす運用設計が必要です。特にGovCloud特有のアカウント分離やアクセス制御を遵守してください。
