# 2026年06月12日

## [Ec2] Amazon EC2 Capacity Blocks for ML is now available in AWS GovCloud (US) Regions

- **公開日**: 2026-06-12 (JST)
- **カテゴリ**: Ec2
- **リンク**: https://aws.amazon.com/about-aws/whats-new/2026/06/amazon-ec2-capacity-blocks-ml-govcloud/

### 概要

Amazon EC2 Capacity Blocks for MLがAWS GovCloud (US-East / US-West)で利用可能になりました。政府機関や規制業界向けにGPUインスタンスを事前予約し、機械学習ワークロード向けの加速コンピュートを確保できます。

### 変更内容・新機能の詳細

EC2 Capacity Blocks for MLは、Amazon EC2 UltraClusters内でのコロケーションにより低レイテンシ・高スループットのGPU容量を予約できるサービスです。予約は最大8週間前まで行え、期間は最長6ヶ月、クラスターサイズは1〜64インスタンスの範囲で指定可能です。GovCloudでは、AWS GovCloud (US-West)でP6-B200インスタンス、AWS GovCloud (US-East)でP6-B200およびP6-B300インスタンスのCapacity Blocksが利用できます。Capacity BlocksはAWS Resource Access Manager (RAM) を使って複数アカウント間で共有できるため、組織横断で予約容量の有効活用やMLインフラ投資の調整が可能です。主な利用例は短期間の事前学習（pre-training）、ファインチューニング、迅速なプロトタイピング、推論負荷のスパイク対応などです。

### 影響範囲・利用シーン

- **対象ユーザー**: 政府機関・規制産業のクラウド運用者、機械学習エンジニア、SRE/インフラチーム
- **利用シーン**: 短期間の大規模学習ジョブやファインチューニングを確実に実行したいケース、推論トラフィックの急増に対する短期的GPU確保、複数アカウントでの予約容量共有による組織横断的なリソース活用
- **運用効果**: 事前予約によりGPUアクセスの競合を回避しスケジュール通りの実験・本番稼働が可能になり、RAM共有で予約資源の稼働率向上とコスト効率化が期待できる

### 技術的な注意点

- **IAM権限**: Capacity Blocksの操作にはEC2とRAM関連の適切なIAM権限が必要です（予約作成・共有・参照権限など）。
- **リージョン制限**: 本リリースはAWS GovCloud (US-West) と AWS GovCloud (US-East) のみ対応です。他リージョンでは別途確認が必要です。
- **インスタンスタイプ**: GovCloudではUS-WestがP6-B200、US-EastがP6-B200およびP6-B300に対応しています。利用前に対象インスタンスタイプを確認してください。
- **予約期間・先行予約**: 先行予約は最大8週間前、予約期間は最長6か月です。短期的・長期的の両方の運用計画に合わせて調整してください。
- **共有(RAM)**: 複数アカウントで共有する場合はAWS RAMを利用します。共有先アカウントの受け入れ設定とIAMポリシー整備が必要です。
- **コスト**: 予約したCapacity Blockには課金が発生します。利用率を上げるための共有運用設計や予算計画が重要です。
- **容量可用性**: 予約可能でも需要状況により希望の時期/サイズが取得できない可能性があります。早めに計画・予約してください。
- **特権・コンプライアンス**: GovCloud特有のアカウント要件やコンプライアンス制約（データ居所やアクセス管理）を満たす必要があります。
