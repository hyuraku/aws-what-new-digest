# 2026年06月08日

## [Rds For Sql Server] Amazon RDS for SQL Server migration cost assessment capabilities now available in AWS Transform 

- **公開日**: 2026-06-08 (JST)
- **カテゴリ**: Rds For Sql Server
- **リンク**: https://aws.amazon.com/about-aws/whats-new/2026/06/amazon-rds-sql-server-cost-assessment-aws-transform/

### 概要

Amazon RDS for SQL Server の移行コスト見積り（TCO）評価が AWS Transform に追加されました。AI エージェントによる解析と what-if 分析で、オンプレの SQL Server を RDS for SQL Server に移行する際の最適なインスタンス、コスト比較、ライセンスオプション評価が可能になります。

### 変更内容・新機能の詳細

AWS Transform の移行評価に RDS for SQL Server の TCO（総所有コスト）評価が追加されました。AI 搭載のエージェントがオンプレ環境のエクスポート（RVTools、CMDB、Transform のディスカバリ出力、その他サードパーティツール）を解析し、ワークロード要件に合う RDS インスタンスタイプや構成を推奨します。what-if シナリオにより、リージョン、稼働率、料金条件などのカスタム前提で複数のコストモデルを比較できます。ライセンスは Bring Your Own Media (BYOM)（既存の SQL Server ライセンスを利用）と License Included (LI) の両方をサポートし、Database Savings Plans による最大約20% の最適化案や、AWS Migration Acceleration Program (MAP) のクレジット・サポート適格性の評価も含まれます。RDS for SQL Server の評価は、既存の AWS Transform の移行評価（Amazon EC2、Amazon FSx、Amazon S3、SQL Server on EC2、仮想デスクトップ等）と組み合わせて総合的な what-if 分析が可能で、スタッフ生産性、運用耐久性、ビジネス機敏性、サステナビリティ等の観点も追加で評価できます。評価は AWS Transform コンソールの Migration Assessment から開始でき、AWS Transform が提供されている全リージョンで利用可能です。

### 影響範囲・利用シーン

- **対象ユーザー**: クラウド移行担当者、データベース管理者、SRE/運用チーム、IT 財務（FinOps）チーム
- **利用シーン**: オンプレ SQL Server の RDS for SQL Server への移行計画立案、コスト比較（BYOM vs LI）、複数シナリオの what-if 分析
- **運用効果**: 最適なインスタンス/ライセンス選定によるコスト削減、移行計画の意思決定高速化、MAP クレジットや Database Savings Plans を含めた現実的な TCO 提示
- **組織的効果**: EC2/FSx/S3 や仮想デスクトップのコストモデリングと統合できるため、複合的な移行戦略と総合的な投資判断が可能

### 技術的な注意点

- **IAM権限**: AWS Transform コンソールの利用と評価開始、データインポートに必要な IAM 権限を事前に確認・付与してください（Transform の操作、S3 へのアップロード権限等）。
- **リージョン制限**: 記載の通り "AWS Transform が提供されている全リージョン" で利用可能ですが、まず自組織の利用リージョンでサービス提供状況を確認してください。
- **コスト**: AWS Transform の利用や追加の解析機能に関する料金、及び評価結果に基づく RDS のランニングコストや Database Savings Plans 適用可否、MAP クレジット適格性は別途確認が必要です。追加料金が発生する可能性があります。
- **データ入力**: RVTools、CMDB、Transform ディスカバリ出力、その他サードパーティデータなど複数の入力フォーマットをサポートします。入力データの正確性が評価精度に直結するため、事前にデータ整備を行ってください。
- **ライセンス**: BYOM（既存ライセンス持込）と License Included の両オプションを評価できます。BYOM を選択する場合は既存ライセンスのサポート条件やライセンス移行ルールを確認してください。
- **前提の検証**: what-if シナリオは前提（リージョン、利用率、料金プラン等）に依存します。想定値や利用パターンを現実に即して設定し、複数シナリオで検証することを推奨します。
- **セキュリティ/コンプライアンス**: エクスポートしたオンプレ情報をクラウドにアップロードする際は機密情報の扱い、社内ポリシーおよび法令順守（データ保護）を確認してください。
