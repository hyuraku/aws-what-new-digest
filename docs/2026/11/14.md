# 2026年11月14日

## [RDS] Aurora PostgreSQL with express configuration now supported in CloudFormation

- **公開日**: 2026-11-14 (JST)
- **カテゴリ**: RDS
- **リンク**: https://aws.amazon.com/about-aws/whats-new/2026/11/aurora-postgresql-cloudformation/

### 概要

Aurora PostgreSQL の express configuration を、AWS CloudFormation からデプロイできるようになりました。クラスターとプライマリ DB インスタンスを1つのプロパティ宣言で作成でき、テンプレートを簡素化できます。

### 変更内容・新機能の詳細

AWS::RDS::DBCluster リソースに、作成専用（createOnly）の withExpressConfiguration プロパティが追加されました。このプロパティを使うと、CloudFormation テンプレートでクラスターとプライマリ DB インスタンスを個別に定義・管理することなく、Aurora PostgreSQL の express configuration を利用したデータベースを作成できます。express configuration では、Aurora Serverless データベースを数秒で作成してクエリを実行できます。CloudFormation でのサポートは、Aurora PostgreSQL の express configuration が提供されているすべての AWS リージョンで利用できます。

### 影響範囲・利用シーン

- **対象ユーザー**: Aurora PostgreSQL を CloudFormation による IaC で管理する開発者、プラットフォームエンジニア、運用チーム
- **利用シーン**: CloudFormation テンプレートから Aurora PostgreSQL の express configuration を使ったクラスターを自動作成する場合
- **運用効果**: クラスターとプライマリ DB インスタンスの定義をまとめられ、テンプレートの記述やリソース管理を簡素化できます。データベースを短時間で用意できるため、開発・検証環境の構築にも役立ちます

### 技術的な注意点

- **プロパティ**: withExpressConfiguration は AWS::RDS::DBCluster の作成専用プロパティです。更新時の動作や置換要否は、CloudFormation リソースリファレンスで確認してください
- **リージョン制限**: Aurora PostgreSQL の express configuration が提供されているリージョンで利用できます。利用前に対象リージョンの提供状況を確認してください
- **リソース管理**: express configuration がプライマリ DB インスタンスを作成するため、通常の構成のようにインスタンスをテンプレートで別途モデル化・管理する必要はありません
- **コスト**: データベースの利用料金が発生します。料金は構成や使用量、リージョンによって異なるため、Aurora の料金情報を確認してください
