# 2026年11月27日

## [RDS] Amazon RDS for PostgreSQL supports minor versions 18.7, 17.12, 16.16, 15.20, and 14.25 

- **公開日**: 2026-11-27 (JST)
- **カテゴリ**: RDS
- **リンク**: https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-postgresql-18-7-17-12-16-16-15-20-14-25/

### 概要

Amazon RDS for PostgreSQL で、マイナーバージョン 18.7、17.12、16.16、15.20、14.25 が利用可能になりました。AWS は、以前のバージョンに含まれる CVE への対応や、コミュニティによる修正・改善を取り込むため、最新マイナーバージョンへのアップグレードを推奨しています。

### 変更内容・新機能の詳細

対象となる PostgreSQL のメジャーバージョンと新しいマイナーバージョンは、18.7、17.12、16.16、15.20、14.25 です。アップグレードは、メンテナンスウィンドウ中に自動マイナーバージョンアップグレードを利用して実施できます。複数環境を運用する場合は、AWS Organizations の Upgrade Rollout Policy を使い、優先度の低い環境から段階的に適用して検証した後、重要な環境へ展開できます。また、RDS Blue/Green Deployments を利用すれば、切り替え時のダウンタイムを抑えたアップグレードを計画できます。アップグレードは RDS コンソールまたは AWS CLI から実施できます。

### 影響範囲・利用シーン

- **対象ユーザー**: Amazon RDS for PostgreSQL を運用するデータベース管理者、開発チーム、SRE／運用チーム
- **利用シーン**: CVE 対応や PostgreSQL の不具合修正・改善を取り込むためのマイナーバージョンアップグレード
- **運用効果**: 自動アップグレードや段階的なロールアウトにより、複数環境への適用を計画・管理しやすくなります
- **ダウンタイム対策**: Blue/Green Deployments を利用して、新旧環境を準備したうえで切り替え、停止時間の抑制を目指せます

### 技術的な注意点

- **対象バージョン**: 18.7、17.12、16.16、15.20、14.25 が対象です。利用中のメジャーバージョンに対応する更新先を確認してください
- **アップグレード計画**: 本番適用前に、下位環境でアプリケーションとの互換性や動作を検証してください。メンテナンスウィンドウと自動マイナーバージョンアップグレードの設定も確認してください
- **リージョン制限**: 提供状況はリージョンによって異なる場合があるため、利用リージョンでの対応状況を確認してください
- **コスト**: アップグレード自体の料金や適用条件は RDS の料金体系を確認してください。Blue/Green では並行稼働する環境の DB インスタンスなどに通常の利用料金が発生する場合があります
